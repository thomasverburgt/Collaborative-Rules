# Collaborative Rules

This repository is the authoritative, reusable documentation set for cross-project collaboration rules, personas, evidence and decision practices, GitHub document control, and session templates.

The full playbook is maintained in [`docs/collaboration-playbook/`](docs/collaboration-playbook/).

## Governance

Documentation changes are handled like code: work on a branch, use a pull request, review the change, and merge the approved baseline to `main`.
